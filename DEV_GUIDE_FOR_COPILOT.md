# RAKSHA-IRELAND Development Guide

This document serves as a comprehensive guide for developing the RAKSHA-IRELAND SOS app using VS Code and GitHub Copilot.

## Development Workflow

### Phase 1: Project Setup ✅
- [x] Initialize git repository
- [x] Create project structure
- [ ] Setup GitHub repository

### Phase 2: Mobile App Development
- [ ] Initialize Expo React Native app
- [ ] Install required dependencies
- [ ] Create core screens and components
- [ ] Implement location tracking and SOS functionality

### Phase 3: Backend Development
- [ ] Setup AWS Lambda functions
- [ ] Configure DynamoDB, SES, and Cognito
- [ ] Deploy API Gateway endpoints
- [ ] Test backend functionality

### Phase 4: Admin Panel Development
- [ ] Create React/Vite dashboard
- [ ] Implement user approval workflow
- [ ] Deploy to GitHub Pages or AWS Amplify

### Phase 5: Integration Testing
- [ ] End-to-end workflow testing
- [ ] Mobile app testing with Expo Go

## Key Technologies

- **Mobile**: Expo React Native, H3 geospatial indexing
- **Backend**: AWS Lambda, DynamoDB, SES, Cognito
- **Admin**: React, Vite, GitHub Pages/Amplify
- **Tools**: VS Code, GitHub Copilot, AWS CLI

## Development Notes

- All operations performed within VS Code terminal
- Browser access only for AWS credential setup and domain verification
- Automated deployment scripts for all components
